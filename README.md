# Brader TV Glass
Android TV launcher prototype with a translucent glass-style dashboard.

## Current prototype
- Transparent glass UI and TV-friendly layout
- JDT match panel and prayer-time panel (placeholders)
- App tiles and directional focus movement
- GitHub Actions workflow for building a debug APK

## Important limitations
JDT fixtures, prayer times, weather, wallpaper rotation, real app launching, and debloat features are not live/implemented yet. Demo values must not be treated as real schedules or prayer times. Keep the stock launcher enabled until the APK is tested and rollback is confirmed.
